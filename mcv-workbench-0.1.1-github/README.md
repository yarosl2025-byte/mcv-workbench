# MCV Workbench

Устанавливаемое веб-приложение (PWA): планировщик, уведомления, танки и замеры, бункер и масло, синхронизация.
Работает офлайн; данные хранятся на устройстве (IndexedDB) и синхронизируются через облачную базу (Supabase).

В репозитории только код. Данных здесь нет: задачи, замеры, калибровки и параметры судна
хранятся на устройствах и в облачной базе, доступ к ним — только с кодом пространства.

- `index.html`, `css/`, `fonts/`, `icons/`, `manifest.webmanifest`, `sw.js` — оболочка (офлайн).
- `js/store.js` — хранилище и синхронизация; `js/app.js` — экраны; `js/clo.js`, `js/tanks.js` — расчёты.
- `supabase/setup.sql` — таблица для синхронизации.
